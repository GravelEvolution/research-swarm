# 每个科研任务的独立检索库

`prepare_source(original, destination, task_id, title, description, import_existing=False)` 返回本任务的独立原检索程序目录，可直接传入 `Library`。首次创建采用同目录暂存后改名；已有目录必须带匹配的管理清单，禁止覆盖其他目录或其他任务。重复调用仅更新当前题目、描述、关键词和检索根，保留论文、证据、PDF 及之后自行配置的模型信息。

新任务默认没有论文和证据，有本课题自己的检索根。配置中只有本任务的 topic，数据位于 `tasks/<task_id>/data/paper_research.sqlite`。原始项目代码和数据库只读，不在其中运行初始化或检索。

迁入任务使用 SQLite 只读备份，保留论文、证据、事实、评分依据和历史结构 ID。只复制 `Library` 校验过的 PDF，并将副本的 `PDFPath` 改为任务自己的文件；无法验证的旧路径置空。历史评分和分类是迁入资料，不会被伪装成新任务的模型研究。

仅复制固定名单中的 Python 运行文件。不会复制 `.env`、日志、模型密钥、原模型供应商配置、`node_modules` 或其他任务的数据。目的地最初的模型配置为空；公开检索不使用模型 API key。上层工作区可用用户唯一配置的模型密钥分析资料，无需为检索另配密钥。

受管副本的 `swarm_task_scope.py` 替换旧程序中的多模态专用构树和评分规则：节点来自当前课题及其关键词；排序依据关键词覆盖与引文数量，新颖性等未核验项用中性分且带明确限制说明。OpenAlex 检索不限定 IEEE；失败时尝试无密钥 Crossref，再尝试公开 arXiv。复制后的执行器遵守 `top_k` 入库上限，并默认关闭自动 PDF 下载。

这些适配只负责公开资料检索和透明规则整理，不等于模型科研或复现实验。公共接口可能限流、不可用或缺少摘要；没有摘要的论文仍保留空证据。关键词匹配不等于语义相关性判断，后续分析与切面细化由工作区的模型执行。来源不可用时明确失败，不要求用户新增其他服务密钥。
