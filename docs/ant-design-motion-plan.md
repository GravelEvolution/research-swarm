# Ant Design 与内容过渡

按用户 2026-09-26 的补充替代 Semi Design。保留对话式科研任务、需求版本、3D 图与单 Key 配置，不变更研究数据。

1. 使用 Ant Design 6 标准组件和中文语言包迁移按钮、输入框、抽屉、弹窗、标签、反馈及标签页。
2. 复现指定 Text reveal 的字素入场：14px 模糊、轻微上浮/翻转、850ms、25ms 字间错峰；长文本压缩错峰总时长，避免等待。高频状态更新使用同类短过渡。
3. 新文本只处理新增/修改的字素；普通动态数据使用局部元素过渡；图节点使用局部柔化再清晰。禁止后台轮询触发未变化内容重播，禁止重建图或干扰输入法。
4. 减少动态效果偏好下取消模糊、位移与翻转。动画可中断，卸载时取消。
5. 用状态/字素测试、构建和隔离浏览器验证新建、需求编辑、研究图、结果、详情与设置；不操作用户现有研究进行测试。
